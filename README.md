# One Letter for Your Day

A one-letter diary entry for make.fun's "One Letter for Your Day" bounty.

The whole entry is a single character — the letter **B**, standing for the
word that describes the day: **buffering**. The whole day kept loading and
never quite arrived: the bus, the laptop, the kettle, the reply that never
came — all spinning.

`main.py` writes exactly that one letter to `/output/entry.txt`, which is
all the sealed gate allows: one character, A to Z, nothing else.

Run it with:

```sh
python3 main.py
```
